## 🚀 How to Run
You can open and execute each notebook locally or directly in Google Colab:
1. Clone the repository:
   ```bash
   git clone https://github.com/bivash-biswal/AI-LAB-experiments.git
   ```
2. Navigate to any experiment folder:
   ```bash
   cd AI_LAB_EXPT/EXPT1
   ```
3. Open the `.ipynb` notebook in VS Code, Jupyter, or click the **Open In Colab** badge inside each notebook.
